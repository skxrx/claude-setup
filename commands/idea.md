# Business Ideation

Brainstorm: $ARGUMENTS

Launch `product-strategist` agent to:

1. If a specific area is given — deep dive into that area
2. If no specific area — generate top 5 ideas based on current wallet state

## For each idea, provide:
- **What:** Feature description (2-3 sentences)
- **Why:** User pain point it solves
- **Revenue:** How it makes money (or improves retention)
- **Complexity:** T-shirt size (S/M/L/XL) + key technical challenges
- **Competition:** Who has it, who doesn't
- **Verdict:** Build now / Defer / Skip + reasoning

## Also consider:
- Regulatory implications
- Security surface increase
- User experience impact
- Chain-specific opportunities (Bitcoin-only features, EVM DeFi, Solana speed)
